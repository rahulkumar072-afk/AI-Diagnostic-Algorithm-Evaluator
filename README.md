# AI Diagnostic Algorithm Evaluator — Week 3
**Student:** Rahul Kumar

## Objective
Compare Decision Tree, Support Vector Machine (SVM), and Neural Network algorithms for a healthcare diagnostic classification task.

## Dataset
Scikit-learn's Breast Cancer Wisconsin (Diagnostic) dataset: 569 samples, 30 numeric features, two classes.

## Metrics
Accuracy, Precision, Recall, F1-score, ROC-AUC, and training time.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `app.py` — interactive Streamlit application
- `requirements.txt` — dependencies
- `Week3_Algorithm_Selection_Report.docx` — report

**Disclaimer:** Educational prototype only; not a clinical diagnostic system.
